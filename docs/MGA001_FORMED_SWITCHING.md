# MGA-001/I — Discovering the switching Ground by fibre equivalence

A source with M divisible by q assigns an affine action to each residue
r in (Z/qZ)^2. Put h=M/q. On the fibre z=r+qk, an affine row (a,b,c)
has the same action as (a mod h,b mod h,c+(a-a mod h)r_x+
(b-b mod h)r_y mod M). This follows because qh=M. The independent
checker tests the two fibre generator differences and the anchor r.
For q=M the fibre is a singleton; the formula remains sound.

Normalize every declared layer before deriving its action label.
Feed exact normalized matrix identities and original residue successors
into native INTENT-001. Its minimal Moore quotient distinguishes
precisely the future words of these chosen action labels. It may split
equal current labels if successor observations differ. Minimality is
relative to this canonical action alphabet, not among all conceivable
affine extensions or nonlinear encodings. No raw physical state is lost;
only switching control is reduced. The same MGA-001/H ordered path
compiler and independent affine-probe checker operate over the formed
quotient, and bind the original source and quotient machine identities.
The native finite observer compiler currently limits this adapter to
q^2<=64; H remains available for larger declared residue spaces.
The input is a complete declared source table, not black-box learning.

## Reproduction

    node experiments/mga001_fibre_quotient.js
    python -m unittest discover -s tests -p test_formed_switching_ground.py -v

The independent JS experiment constructs 64 different declared matrices
on a 2^80-state source. All 64 normalize to two actions. Future observation
refinement requires four switching classes, not two: the current label
does not identify the future path. Independent pair-orbit comparison
checks all 2016 unordered residue pairs, including 1536 distinguishable
pairs and maximum distinguishing depth one. 1024 fibre checks, 1024
direct replay comparisons and 1024 large-coordinate semigroup comparisons
pass. Independent evidence is retained as JSON. Python native integration
checks remain distinct from the executed JS campaign. This is a constructed
family and not a demonstration of arbitrary chaos reduction.
